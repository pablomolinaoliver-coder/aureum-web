# Aureum Digital Studio — Web

Sitio estático de [aureumdigitalstudio.com](https://aureumdigitalstudio.com): diseño web, SEO local, redes sociales y automatización con IA para negocios locales.

- HTML/CSS/JS puro, sin dependencias. Desplegado con Vercel.
- `proyectos/` contiene las demos en vivo del portfolio.
- `en/` es la versión en inglés.

Para publicar cambios: commit + push a `main` (Vercel despliega automáticamente).
